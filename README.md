# Redemption
Power BI dashboard for tracking employee coupon redemptions using vendor-managed Google Sheets data, with insights on redeemed, delivered, and pending coupons, BDT values, monthly trends, and top reward categories.
# Employee Coupon Redemption Dashboard

This project is a Power BI dashboard developed to track and analyze employee coupon redemption data. The source data is maintained by the vendor in Google Sheets, where employee redemption details such as coupon name, quantity, price, delivery status, and redemption amount are recorded.

The dashboard is connected with Google Sheets and provides an automated view of total redemptions, delivered coupons, pending coupons, redeemed amount, delivered amount, and pending BDT value. It also helps identify top redeemed coupon categories, monthly redemption trends, and reward-wise performance.

## Project Objective

The main objective of this dashboard is to make coupon redemption tracking easier, faster, and more transparent for HR and vendor coordination. Instead of manually checking Google Sheets, the dashboard provides a clear visual summary of redemption status, pending delivery, and monthly performance.

## Key Insights

- Total redeemed coupons
- Delivered coupon count
- Pending coupon count
- Total redeemed BDT value
- Delivered BDT value
- Pending BDT value
- Top 5 redeemed coupon categories
- Monthly redemption and BDT trend
- Reward-wise redemption breakdown
- Employee-wise pending coupon tracking

## Tools Used

- Power BI
- Google Sheets
- Power Query
- DAX
- Data Visualization
- Dashboard Design

## Dashboard Features

- Google Sheets data connection
- KPI cards for quick summary
- Month-wise slicer
- Reward-wise redemption table
- Pending coupon tracking
- Donut chart for top coupon categories
- Monthly trend analysis
- Stacked column chart for coupon-wise monthly redemption

## Business Use Case

This dashboard can be used by HR, Admin, Rewards, or Vendor Management teams to monitor coupon redemption activities, track pending deliveries, and make reporting more efficient. It reduces manual work and improves visibility into employee reward redemption status.
